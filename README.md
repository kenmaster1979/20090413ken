# 画面拉伸测试（vivo Pad Air）

这是给你自己平板用的测试工具：**不改游戏文件、不注入进程**。  
你已经试过用 Shizuku 改分辨率，结果只有黑边——这是正常的。OriginOS / Android 会**保比例**，不会像电脑显卡那样把 4:3 画面拉满。

本应用改用「虚拟屏合成拉伸」：

1. 用 Shizuku 建一块 **4:3 或 16:9** 虚拟屏
2. 把游戏启动到这块虚拟屏上（游戏会按这块屏的比例渲染）
3. 把画面**非等比**铺满平板物理屏（Pad Air 为 2800×1840，约 3:2）

## 你现在该怎么做

1. 先把以前改过的分辨率还原，避免桌面和游戏继续带着黑边：
   - 打开本应用，点 **还原系统分辨率**
   - 或用电脑执行：`adb shell wm size reset` 和 `adb shell wm density reset`
2. 安装 [Shizuku](https://shizuku.rikka.app/)，用 **无线调试 / ADB** 启动（不要用 Root 启动，否则可能报 `packageName must match the calling uid`）
3. 安装本应用，打开后点 **授权 Shizuku**
4. 选择无畏契约，勾选「启动前先强制停止」
5. 选 **4:3 端游式**（人物变宽）或 **16:9 填黑边**（把上下黑边拉开）
6. 点 **开始合成拉伸**。左上角 **退出** 随时关掉虚拟屏，回到原样
7. 看对局里的人物和准星，不要只看大厅 UI

控制中心可添加「还原分辨率」磁贴，防止改乱系统分辨率后找不到还原入口。

## 可能看到的结果

- **人物明显变宽、画面铺满** → 合成拉伸有效，这就是移动端能做到的「真实拉伸」
- **游戏里仍有黑边，再被一起拉开** → 游戏自己锁了 16:9，不跟虚拟屏比例走。这种情况下，不改游戏就做不到端游那种 4:3
- **能看见画面但点不准** → 告诉我机型和系统版本，再调触摸映射
- **延迟变大** → 这是合成拉伸的代价，没法做到显卡直通那么低延迟

## 风险

- 多一层合成，FPS 手感可能变差
- 反作弊可能识别虚拟屏 / 模拟触摸
- 请用小号测试

## 备用还原

```bash
adb shell wm size reset
adb shell wm density reset
```

若拉伸界面卡住，按平板多任务划掉本应用即可释放虚拟屏；仍异常就重启平板。

## 用 Android Studio 编译

1. 用 Android Studio 打开本仓库
2. JDK 17，SDK 35
3. `Build > Build Bundle(s) / APK(s) > Build APK(s)`
4. 把 `app/build/outputs/apk/debug/app-debug.apk` 装到平板

命令行：

```bash
./gradlew assembleDebug
```
